# TIDE 第四轮检索模型实验包

真实权重：BAAI/bge-base-zh-v1.5 全参数微调，训练完成5轮822步，采用验证集选定的step100。全参数、顶层对照、冻结基线均已评测。合成数据2000 Topics/20000查询，目标家族train48、validation24、test24互不重合；仍未完成困难样本独立双审。

## 快速运行

Python3.10+，无需PyTorch或GPU：

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python demo.py --query '夜班清洁那部分水量该放在哪个时段？'
```

将topics.json换成自己的[{"topic_id":"…","text":"有来源的话题概述与关键锚点"}]。完整输入上限query128 tokens（含固定BGE指令），Topic384 tokens；空输入、超预算输入应进入宿主fallback，示例明确报错。主题向量可按模型版本预先生成和缓存，权重更新后必须重建索引。

输出是768维L2归一化向量及余弦检索候选；assignment和attribution_probability均为null，不自动绑定或创建话题。本示例没有实现图谱、权限或实体解析。

## 实测和边界

目标隔离合成测试Top1：冻结84.38%、全参数99%、顶层94.31%。这些是脚本标签实验结果，不是真实世界正式成绩。

纯向量诊断阈值下，全参数覆盖91.69%、接受错误4.64%；加入移除真实目标反事实后接受错误40.86%，不适合作自动归题。不得用Top1=99%推断安全归题或概率可靠。

原技术文档§4.3的90%覆盖/3%误归题门槛针对融合分数S（向量D、词法L、显式证据E、图谱G、时间H和矛盾C），不能把纯向量阈值当已校准的融合阈值。仅增加已登记客户名/简称的E、C也未通过验证，报告如实保留；这份包不冒充完整系统已验收。

FP32 ONNX固定探针一致性通过；原始动态INT8失败，后续量化诊断报告见reports。除非单独报告明确通过，量化文件均不得视为已验收；麒麟SDK及目标机性能尚未实测。

目录weights为可继续微调的原始权重；encoder为ONNX/tokenizer；manifest.json记录文件哈希。研究目标仍未全部达成。


## 新增混合精度INT8

运行 `python demo.py --query '你的请求' --precision mixed-int8`。首尾两层保留FP32，其余60/72个常量权重MatMul使用W8A8；嵌入和原本浮点算子仍按导出图处理，不能称全图全INT8。

经过训练输入统计平衡（alpha=.25），固定工程探针最低余弦.99323；另取未用于量化拟合的测试文本128条query、128条Topic，batch1/16对齐最低.99525，均超过.99。报告包含完整数值和文件哈希。前一版只保留4个敏感算子的候选在验证查询中失败，未收入本包。

以上证明这份混合精度ONNX在所测文本、训练侧ONNX Runtime中数值通过，不证明麒麟SDK兼容、目标x86性能或自动归题达标。默认FP32；混合版须单独指定，不静默替换模型版本。
