# Security / 安全问题反馈

Please report vulnerabilities privately through [GitHub private vulnerability reporting](https://github.com/xzgzszrh/MemPulse/security/advisories/new).

安全问题请通过 [GitHub 私密漏洞报告](https://github.com/xzgzszrh/MemPulse/security/advisories/new)提交。请说明受影响版本、复现步骤、预期影响，以及经过脱敏的必要日志。

Do not post credentials, personal memory databases or full exploit details in public issues. 不要在公开 Issue 中上传凭据、个人记忆数据库或尚未修复漏洞的完整利用细节。

Reports concerning the MemPulse customization should go to this repository; upstream OpenCode maintainers are not responsible for this customization. 定制功能的问题由本项目接收，上游联系方式不代表其负责 MemPulse 代码。
