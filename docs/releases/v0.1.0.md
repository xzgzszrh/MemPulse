# MemPulse v0.1.0

首次公开发布 / Initial public release.

## 中文

本版本提供可从源码构建的本地话题记忆工程：Python 服务、CLI/MCP/HTTP、OpenCode 定制桌面、完整 TIDE revision4 模型权重，以及中英双语 README 和架构配图。自研代码采用 Apache-2.0，第三方许可证保持不变。

### 下载

- **macOS Apple Silicon 安装包**：`MemPulse-Code-1.18.30-mempulse.20260915.1-mac-arm64.dmg`，内置 Python 运行时、ONNX Runtime 与 FP32 检索模型。
- **完整源码与模型**：`mempulse-v0.1.0-source-with-models.tar.gz`，包含真实权重，不依赖 Git LFS 下载；解压后在目录内运行 `python3 scripts/verify_models.py`，再按 `docs/BUILD.md` 构建。
- **校验与许可**：`SHA256SUMS`、`LICENSE`、`NOTICE`。下载后使用 `shasum -a 256 -c SHA256SUMS` 校验同目录的全部附件；若只下载部分文件，请核对对应行。

Git 用户可直接克隆仓库并执行 `git lfs pull`。GitHub 自动生成的 Source code ZIP/TAR 不保证含有真实 LFS 权重；需要一次获取完整工程时，请选择上述 `source-with-models` 附件。

### 验证

- 后端及真实模型：70 项测试通过。
- 独立 WebUI：构建成功，1 项验收测试通过。
- Electron：类型检查、服务与前端生产构建通过。
- 打包后的记忆服务：25 项检查通过，包含 15 次检索及工作区持久化切换。
- macOS DMG：磁盘镜像校验通过。

### 当前边界

安装包未签名、公证，仅验证 macOS Apple Silicon。Linux/麒麟构建脚本已提供，仍需目标机器验证。统一构建入口暂不覆盖 Intel Mac 和 Windows。混合 INT8 权重属于实验配置，默认使用 FP32。GUI 尚未完成全面人工验收。使用云端大模型对话仍需自行配置提供商和凭据。

`v0.1.0` 是 MemPulse 项目发布标签；安装包内部版本保留已验证构建的 `1.18.30-mempulse.20260915.1`，基于 OpenCode 版本编号。

## English

This release contains a buildable local topic-memory system: the Python service, CLI/MCP/HTTP adapters, a customized OpenCode desktop, full TIDE revision4 model weights, and bilingual documentation with architecture illustrations. Original MemPulse code is licensed under Apache-2.0; third-party licenses are retained.

### Downloads

- **macOS Apple Silicon DMG** bundles Python, ONNX Runtime and the FP32 retrieval model.
- **`mempulse-v0.1.0-source-with-models.tar.gz`** contains actual model files as well as the source. Extract it, run `python3 scripts/verify_models.py`, then follow `docs/BUILD.md` or the English README. Git LFS is not needed for this archive.
- **`SHA256SUMS`, `LICENSE`, `NOTICE`** provide checksums and licensing information. With all assets in one directory, run `shasum -a 256 -c SHA256SUMS`; for partial downloads, verify the corresponding entries.

Git users should run `git lfs pull`. GitHub's automatically generated source archives may contain LFS pointers; use the explicit source-with-models asset for a complete delivery.

### Validation and limitations

70 backend/model tests and 1 WebUI acceptance test passed. Desktop type checking and production builds passed. The packaged service passed 25 checks, including 15 retrieval requests and workspace persistence. The DMG checksum was verified.

The macOS build is unsigned and not notarized. Only Apple Silicon packaging was validated; native Linux/Kylin workflows still need target-machine checks. The unified build entry does not cover Windows or Intel Macs. Mixed INT8 remains experimental, and FP32 is the default. This is not a complete manual GUI acceptance test. Cloud language-model conversations require the user's own provider credentials.

The project release tag is `v0.1.0`; the validated desktop binary retains its OpenCode-derived internal version, `1.18.30-mempulse.20260915.1`.
