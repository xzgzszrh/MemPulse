# Tracework

A memory is a path through time. The visual language uses continuous lines, sparse junctions and deliberate changes of weight to suggest continuity without turning the system into a generic cloud of nodes. Each connection earns its place.

Warm paper and near-black ink provide a calm editorial foundation. A single vermilion accent identifies the thread being followed. Muted secondary lines carry context while remaining visually subordinate. The palette extends the existing red MemPulse identity.

The composition balances a confident typographic anchor against a precisely constructed field of relationships. Large areas of quiet space make the small details legible. Alignment, baseline rhythm and optical spacing receive the same painstaking attention as the central illustration.

The diagrams are crafted as technical explanations: labels describe real components, connectors indicate real interfaces, and the distinction between observation, retrieval and confirmed writes stays visible. No decorative metric implies a performance claim. The finish should reflect deep technical and visual expertise.

All images are original explanatory illustrations, not application screenshots. English and Chinese variants share geometry and meaning. PNGs render consistently on GitHub; their source is `scripts/render_readme_assets.py`. Rendering requires Pillow, Instrument Sans/IBM Plex Mono fonts and a CJK font. Fonts are not redistributed here.
